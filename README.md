# Grass51 support

Public English and Spanish privacy and support pages for Grass51, by Facundo Deshays.

- Privacy: https://facudes.github.io/grass51-support/privacy/
- Support: https://facudes.github.io/grass51-support/support/
- Contact: desfacundo@gmail.com

Static HTML and CSS hosted on GitHub Pages from the root of `main`. No JavaScript, analytics, web forms or external fonts. GitHub Pages processes visitor request data under GitHub's own privacy practices, as explained in the privacy policy.

Keep both languages and the in-app offline privacy copy consistent when changing policies or contact information. Update the effective date when practices change.
